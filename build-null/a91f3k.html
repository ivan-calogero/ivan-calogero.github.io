Frammento 02 — Controllo accessi

Legacy login

Il vecchio manutentore aveva una pessima abitudine: lasciava annotazioni direttamente nei documenti. Il nome operatore è auditor. La password non appare nella pagina.

Più di quindici anni fa un piccolo hacking game iniziava proprio così: una schermata di login e una password lasciata, ingenuamente, dentro un commento HTML.
